# UIFONT.TTF

`UIFONT.TTF` is a static TrueType subset built for this app from:

- **Noto Sans SC** (variable), © 2014-2021 Adobe, with Reserved Font Name
  "Source".
- **Noto Sans KR** Regular, © 2014-2021 Adobe, with Reserved Font Name
  "Source".

Both families are licensed under the **SIL Open Font License, Version 1.1**;
the complete license text is in `FONT-OFL.txt`. Source files and SHA-256
digests are recorded in `FONTINFO.json`.

The build merges a Simplified/Traditional Chinese and Japanese subset with the
Hangul glyphs used by the Korean catalog, then renames the result
"Lut Camera Sans". It is a modified subset, not the original Noto fonts, and
does not use the reserved name "Source".
