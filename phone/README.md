# Sony LUT 手机传片（SonyLutRemote）

A7R2 机内胶片相机的本地配套 App，包名 `org.hongen.sonylutremote`。相机 App
打开期间，手机加入相机自己建立的 Wi-Fi，自动接收新照片；录像必须先在相机上勾选，
再在手机端点按下载。

本 App 与相机 APK 都使用本地测试签名，**仅供自用、不对外分发**。

## 传输边界

| 相机模式 | 手机可收到 | 手机永远收不到 |
| --- | --- | --- |
| 真 LUT | LUT 成片（`graded`） | 原片 JPEG、RAW |
| 近似配方 | 相机直出 JPEG（同一张） | 无额外文件 |
| 录像 | 仅相机“手机传输 → 选择录像”中已勾选、已写完的文件 | 未勾选、正在写入、路径外的文件 |

照片自动传输只发生在**相机 App 存活期间**：胶卷库或取景器均可。回到 Sony 原生
拍摄前，相机会主动关闭传输服务、端口和 Wi-Fi Direct。

手机只使用相机本地 Wi-Fi，没有互联网，也不会把任何文件上传到别处。

## 首次配对

1. 相机打开 **A7R2胶片相机 → MENU → 更多 → 手机传输**，选择“开启手机传输”。
2. 等待该页显示 **Wi-Fi 名称（SSID）**、**Wi-Fi 密码**、**配对码** 和 **地址**。
   首次开启可能需要几秒建立 Wi-Fi Direct 组。
3. 手机安装 `dist/SonyLutRemote.apk`，打开“Sony LUT 手机传片”。
4. 把四项信息填入配对信息区，点“保存配对信息”。地址通常是
   `192.168.122.1`，端口默认 `8080`；以相机页面实际显示为准。
5. 点“连接并同步”。

**Android 10 及以上**：加入相机 Wi-Fi 时，系统会弹出一次确认框，要求确认连接
这个没有互联网的 Wi-Fi。这是 Android 的安全行为，App 无法绕过，请在系统提示中
允许。只有相机 `/v1/ping` 探测通过后，手机才显示“已连接”。

Android 6–9 需要定位权限才能保存/连接 Wi-Fi 配置；App 会在首次连接时请求。

## 日常使用

1. 相机进入胶片相机 App，在“手机传输”页确认已开启。
2. 手机点“连接并同步”。新拍的照片会自动下载；首次同步默认把相机里已有的旧照片
   标记为“已跳过”，不会突然拉取整个卡。需要旧照片时点“加入已跳过的照片”。
3. 下载中可把手机切到后台；前台服务会继续当前队列。停止后重新连接会从
   `.part` 文件续传，按 ETag 校验，相机文件变化时从头重新下载。
4. 保存位置：
   - Android 10 及以上：系统相册 `Pictures/SonyLUT`、`Movies/SonyLUT`。
   - Android 6–9：公共 Pictures/Movies 目录并触发媒体扫描。

### 录像

录像不会自动传输。先在相机“手机传输 → 选择录像”中用方向键勾选、OK 切换、
保存选择；手机端录像标签页只会列出这些文件。点某一条录像并确认“下载”才开始
传输。传输录像时相机可暂时退出该页，但请保持相机 App 打开。

## 停止与故障排查

- 手机上点“停止”只停止手机同步，不会关闭相机端服务。
- 相机“手机传输 → 关闭手机传输”或退出相机 App，会关闭端口与 Wi-Fi Direct。
- “连接异常 / 连接相机 Wi-Fi 超时”：核对 SSID、密码和相机页地址；确认相机 App
  仍在前台或取景器，且传输已开启。
- “配对码不正确”：以相机页当前配对码为准。相机重新生成配对码后，在手机上更新
  并保存。
- “该录像已不在相机勾选列表中”：回到相机重新勾选，手机再点“立即检查”。
- “文件已变化，请重新同步”：相机端文件被替换，手机已丢弃旧的部分文件，重试即可。
- 相机 Wi-Fi 没有互联网，手机可能提示“此网络无法访问互联网”，选择保持连接。

## 构建与检查

```sh
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export ANDROID_SDK=/home/topeet/Android/Sdk

bash scripts/test_phone.sh          # 台账、Range/ETag 续传主机测试
bash scripts/build_phone.sh         # 输出 dist/SonyLutRemote.apk
python3 scripts/check_phone_package.py
```

构建使用 SDK 36 / build-tools 36.0.0、纯 Java（无 Gradle、无原生库），
`javac --release 7`、D8 `--min-api 23`，并以 `out/test.keystore` 做 v1+v2 测试签名。
检查会拒绝相机包名、Sony 私有类、相机 HTTP 服务器类以及任何原生库。

## 已验证与未验证

主机测试覆盖台账去重、首次同步跳过旧照片、Range 续传、ETag 变化重置和错误码。
手机端 Wi-Fi specifier / legacy 两条路径、真实 A7R2 的 Wi-Fi Direct 配对、息屏传输、
大录像续传和系统确认框仍需在真机上逐项验证；结果在
`docs/A7R2_PORT.md` 的 a7r2.50 清单中记录。不要仅凭主机测试宣称真机已通过。
