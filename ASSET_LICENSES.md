The repository's GPL-3.0-only license applies to original program code and documentation. External assets retain the terms below; GPL does not relicense them.

**Public source scope:** the public repository does **not** ship the ten sample
`.CUB` LUTs, the 176-card POSE data pack/images, or Sony firmware memory maps.
Those files live in the untracked `local-assets/` overlay used by the
maintainer's device builds and are not part of any public source or binary
distribution. A fresh clone builds with an empty LUT catalog; users can import
their own `.cube` files from the camera's SD card. Rows below that describe
excluded files are retained as provenance notes, not as a grant.
